# LLJ Device Link

`LLJ Device Link` 是为 `LilyChan Roshutsu` 开发的 Windows 蓝牙设备联动 Mod。它会读取游戏中的惩罚、道具挡位、心率、快感、露出、任务和 NPC 发现等状态，并按照玩家为每台设备单独设置的强度、时间与波形输出。

当前公开版本：`v1.0.1`

运行环境：Windows 10/11 64 位、Unity 2022.3.50f1、IL2CPP 版游戏。

> 安全提醒：电刺激设备存在风险。第一次使用请将设备和 Mod 强度都调到很低，先用“测试此设备配置”确认通道、强度与波形，再进入正式游戏。任何时候都可以按 `F12` 急停。

## 功能概览

- 内置 BepInEx 6，下载 Release 后可以直接覆盖到游戏根目录，不需要另外安装 Mod 加载器。
- 支持多台设备同时连接，每个游戏事件可以勾选一台或多台设备。
- 每台设备、每个事件都有独立的强度、持续时间、通道或马达、波形配置。
- 惩罚叠加、道具挡位和数值倍率等动态强度事件，可为每台设备单独设置最终强度上限。
- 持续事件会自动结束；轮询异常、对象消失或场景切换时也有约 1.2 秒的停止保险。
- 游戏暂停时会立即清除当前输出，恢复游戏后持续状态会按实际游戏状态重新建立。
- F8 窗口打开时会阻止鼠标穿透到游戏相机、场景交互和游戏 UI。
- 游戏启动时不会自动扫描蓝牙；只有点击“连接设备”才执行一次 10 秒扫描。
- 启动时自动加载 `waveforms` 下的内置及用户自定义波形。

## 支持的设备

| 设备 | 蓝牙名称或识别方式 | 强度范围 | 波形目录 |
| --- | --- | ---: | --- |
| 役次元电击器一代 | `YYC-DJ` / `FF30` 服务 | 0–180 | `waveforms/役次元` |
| 役次元电击器二代 | `YYC-DJ-V2` / `FF30` 服务 | 0–180 | `waveforms/役次元` |

## 下载和安装

1. 打开项目的 [Releases](https://github.com/DT-DT001/LLJ_MOD/releases)，下载 `LLJ-Device-Link-v1.0.1.zip`。
2. 完全退出游戏。
3. 解压 ZIP。压缩包打开后应直接看到 `BepInEx`、`dotnet`、`waveforms`、`winhttp.dll` 等内容。
4. 将压缩包里的全部文件和文件夹复制到游戏根目录，也就是与 `LilyChan Roshutsu.exe` 同一层；出现同名目录时选择合并或覆盖。
5. 启动游戏。第一次启动时 BepInEx 需要生成 IL2CPP 互操作文件，可能比平时慢几十秒，请不要中途关闭。
6. 进入游戏后按 `F8`。能看到“LLJ 设备联动”窗口就说明安装成功。

安装后的关键目录大致如下：

```text
游戏根目录/
├─ LilyChan Roshutsu.exe
├─ winhttp.dll
├─ BepInEx/
│  └─ plugins/LLJDeviceLink/LLJDeviceLink.dll
├─ dotnet/
└─ waveforms/
   ├─ 役次元/
   ├─ 郊狼/
   └─ 玩具/
```

### 更新和卸载

- 更新：退出游戏后，将新版 ZIP 内容再次复制到游戏根目录并覆盖。配置保存在 `BepInEx/config/LLJDeviceLink/settings.json`，正式包不会携带默认配置覆盖它。
- 卸载：退出游戏，删除 `BepInEx/plugins/LLJDeviceLink`。如不再使用任何 BepInEx Mod，再自行删除根目录中的 BepInEx 相关文件。

## 连接设备

连接前请先完成以下准备：

1. 打开 Windows 蓝牙。
2. 打开设备电源并让设备靠近电脑。
3. 关闭可能正在占用设备的手机 App；BLE 设备通常不能同时被手机和电脑控制。
4. 按 `F8`，进入“设备连接”页。
5. 点击“连接设备”。每次点击只扫描 10 秒，发现受支持设备后会立即尝试连接。

设备列表中的内容：

| 项目 | 含义 |
| --- | --- |
| 名称、类型、设备 ID | 当前发现的蓝牙设备及 Mod 判定出的协议类型 |
| RSSI | 蓝牙信号强度；数值越接近 0，通常信号越好 |
| 状态 | 已发现、连接中、已连接、已断开或连接失败 |
| 连接 | 手动连接已发现但尚未连接的设备 |
| 断开 | 断开当前设备并停止其输出 |
| 重试 | 断开后重新建立连接，适合处理临时 GATT 错误 |
| 输出 A/B、电量 | 当前实际输出强度和设备回报的电量；不支持电量回报时显示 `--` |
| 马达模式数 | 飞机杯/跳蛋连接后查询到的 A/B/C 马达能力 |
| 重新加载波形 | 不重启游戏，重新读取 `waveforms` 中的 JSON 文件 |

如果 10 秒内没有找到设备，可以再次点击“连接设备”。同一次扫描中，同一设备只会尝试连接一次。

### 郊狼 3.0 设备页设置

- `A/B 软上限`：通过 BF 指令写入设备的额外强度上限；即使事件强度更高，也不会超过这个值。
- `A/B 频率平衡`、`A 强度平衡`：写入郊狼 BF 配置的通道平衡参数。
- `立即写入 BF`：连接状态下立即把当前安全配置写入设备；每次重新连接也会自动写入。

## 快捷键和窗口

| 操作 | 功能 |
| --- | --- |
| `F8` | 打开或关闭完整配置窗口 |
| `F12` | 立即停止全部已连接设备并禁用联动 |
| `恢复设备联动` | 急停后重新允许事件输出；仍处于活动状态的持续事件会在下一次轮询恢复 |
| 右上角状态条 | 显示已连接设备数量和当前正在输出的设备数量 |

F8 窗口打开期间，Mod 会隔离游戏的相机、世界交互、道具切换和游戏 UI 鼠标事件。关闭窗口的那次鼠标按键完全松开后才恢复游戏输入，避免点击穿透。

## 配置游戏事件

1. 先在“设备连接”页连接所有要使用的设备。
2. 进入“事件配置”页，在左侧选择一个游戏事件。
3. 使用设备名称两侧的 `<`、`>` 切换已连接设备。
4. 对希望响应当前事件的设备勾选 `使用该设备`。
5. 配置该设备的强度、时间、通道或马达以及波形。
6. 切换到下一台设备重复设置。所有更改都会自动保存。

同一个事件可以选择多台设备。例如“失败并进入惩罚”可以同时驱动役次元和郊狼，而两台设备使用不同强度、通道和波形。

### 15 个事件分别表示什么

| 分类 | 事件 | 类型 | 说明 |
| --- | --- | --- | --- |
| 游戏 | 游戏/旅程开始 | 触发 | 进入一段新旅程时输出一次 |
| 游戏 | 失败并进入惩罚 | 触发 | 扣除生命并进入惩罚，但还不是最终 Game Over；支持按累计惩罚次数叠加强度和时间 |
| 游戏 | 游戏最终失败 | 触发 | 游戏进入最终失败时输出一次 |
| 游戏 | 旅程结束 | 触发 | 正常离开或结束当前旅程时输出一次 |
| 道具 | 快感道具运行 | 持续 | 只要任意快感道具仍开启就保持输出，并实时跟随道具挡位；关闭其中一个道具不会关闭其他仍开启道具的输出 |
| 露出 | 衣物露出程度变化 | 触发 | 穿脱衣物导致露出阶段增加或降低时输出；可按当前露出阶段换算强度 |
| 露出 | 完全裸露 | 持续 | 玩家完全裸露期间保持输出，重新穿衣后停止 |
| 露出 | 风险值变化 | 触发 | 实际风险点发生变化时输出；可用实际风险点乘倍率换算强度 |
| 心率 | 心率升高 | 持续 | 心率达到“心率中阈值”后开始，恢复到阈值以下后停止；可按 0–100 心率百分比换算强度 |
| 快感 | 高潮 | 持续 | 游戏处于高潮状态期间输出，状态结束后停止 |
| 快感 | 忍耐/克制 | 持续 | 游戏处于忍耐或克制状态期间输出，状态结束后停止 |
| 任务 | 任务/挑战开始 | 触发 | 任意任务或挑战开始时按配置时间输出 |
| 任务 | 任务/挑战完成 | 触发 | 任意任务完成或挑战达成时输出 |
| 任务 | 任务失败 | 触发 | 任务进入失败状态时输出 |
| 发现 | NPC 警戒/发现玩家 | 持续 | NPC 当前对玩家存在有效目击或感知报告并进入警戒/发现时输出；玩家成功躲开后停止 |

`持续`事件没有“持续时间”选项，因为它们跟随游戏真实状态。Mod 每 0.2 秒续期；状态消失、对象销毁、轮询失败或离开旅程时，最迟约 1.2 秒停止。`触发`事件则按照玩家设置的持续时间输出。

## 每个设备配置项

| 配置项 | 适用范围 | 作用 |
| --- | --- | --- |
| 使用该设备 | 所有设备 | 决定当前事件是否分配给这台设备；取消后立即移除该事件的输出 |
| 启用输出 | 所有设备 | 保留配置但临时禁用输出，方便之后重新启用 |
| 基础强度 | 所有设备 | 当前事件的起始强度；役次元限制 0–180、郊狼限制 0–200、玩具限制 0–20 |
| 强度上限 | 强度会叠加或跟随数值变化的事件 | 当前事件在当前设备上的最终强度上限；每个事件、每台设备独立保存，且不能超过设备硬件范围 |
| 持续时间 | 触发事件 | 一次事件输出多久，范围 0.1–600 秒 |
| 每次惩罚叠加强度 | 惩罚事件 | 第 2 次及以后惩罚在基础强度上增加多少 |
| 每次惩罚叠加时间 | 惩罚事件 | 第 2 次及以后惩罚在基础时间上增加多少 |
| 按事件数值增加强度 | 风险、心率、快感、露出阶段 | 启用 `最终强度 = 基础强度 + 事件数值 × 数值倍率`；计算后仍受设备上限约束 |
| 数值倍率 | 带数值事件 | 每 1 点风险、每 1% 心率/快感或每 1 个露出阶段增加多少强度，支持小数 |
| 通道 A/B | 电击器 | 决定当前事件输出到哪些电击通道；二代和郊狼可为通道分别选择有效输出 |
| 马达 A/B/C | 飞机杯/跳蛋 | 决定当前事件驱动哪些马达 |
| 按游戏道具挡位调强度 | 玩具的“快感道具运行”事件 | 挡位越高，现实设备强度越高 |
| 每挡增加 | 玩具的“快感道具运行”事件 | 游戏道具每提高一挡，现实设备增加多少强度 |
| 多道具合成 | 玩具的“快感道具运行”事件 | `取最高挡`或`相加并限制 20`；只关闭其中一个道具不会误停其他道具 |
| 电击/振动波形 | 所有设备 | 从与设备协议匹配的波形列表中选择输出节奏 |
| 测试此设备配置 | 已连接设备 | 不等待游戏事件，按当前设置测试，最长 10 秒；请先使用低强度 |

### 数值倍率示例

风险事件设置为基础强度 `10`、数值倍率 `0.5`，当前风险值为 `30`：

```text
计算强度 = 10 + 30 × 0.5 = 25
最终强度 = min(计算强度, 当前事件的设备强度上限, 设备硬件上限)
```

每台设备独立计算。例如同一个风险事件可以让役次元使用 `0.5` 倍率、郊狼使用 `1.2` 倍率。

动态上限会显示在以下配置中：失败惩罚次数叠加、玩具按游戏道具挡位变化，以及风险、心率、快感、露出阶段的数值倍率。所有输入和最终协议输出还会再次按设备限制：役次元电击器 `0–180`、郊狼 `0–200`、役次元飞机杯/跳蛋 `0–20`。

## 全局设置

| 配置项 | 作用 |
| --- | --- |
| 心率中阈值 | 心率达到该归一化值后，“心率升高”持续事件开始 |
| 心率高阈值 | 用于区分诊断中的中/高心率状态 |
| 风险中/高阈值 | 用于对风险事件上下文进行低、中、高分类和诊断 |
| 事件监控诊断 | 显示最新捕获的游戏事件、开始/结束状态、来源与挡位，用于排查配置是否触发 |

配置文件位于：

```text
BepInEx/config/LLJDeviceLink/settings.json
```

升级前可以备份这个文件。旧事件目录升级时，Mod 会自动合并旧配置，并保留一份 `settings.pre-1.3.0.json`。

## 波形和自定义波形

Mod 启动时会递归读取游戏根目录的 `waveforms`。新增或修改 JSON 后，可以在“设备连接”页点击“重新加载波形”，无需重启游戏。不同设备的协议格式不能混用。

### 役次元固定模式

```json
{"id":"my-ycy-fixed","name":"我的固定模式","mode":1}
```

### 役次元实时波形

每组数据是 `[频率 1–100, 脉冲时间 0–100]`，每 100 ms 发送一组：

```json
{"id":"my-ycy","name":"我的役次元波形","ycyData":[[10,20],[20,50],[30,80]]}
```

### 郊狼 3.0 波形

每个字符串为 8 字节：前 4 字节是频率 10–240，后 4 字节是波形强度 0–100：

```json
{"id":"my-coyote","name":"我的郊狼波形","pulseData":["0A0A0A0A14283C50","14141414503C2814"]}
```

### 飞机杯/跳蛋振动包络

每个数值范围为 0.0–1.0，用于乘以计算后的实时马达强度：

```json
{"id":"my-toy","name":"我的振动波形","toyData":[0.2,0.5,0.8,1.0,0.5,0.0]}
```

## 常见问题

### 按 F8 没有界面

- 确认文件复制到了真正包含 `LilyChan Roshutsu.exe` 的目录，而不是多套了一层文件夹。
- 检查 `BepInEx/LogOutput.log` 是否出现 `LLJ Device Link 1.0.1 loaded`。
- 第一次启动请等待 BepInEx 完成 IL2CPP 文件生成。

### 点击“连接设备”找不到设备

- 确认 Windows 蓝牙已开启、设备电量充足并靠近电脑。
- 彻底退出手机上的设备控制 App。
- 再次点击会重新执行一轮 10 秒扫描。
- 查看设备页错误信息以及 `BepInEx/LogOutput.log`。

### 设备连接了但没有输出

- 进入“事件配置”，确认当前事件已对该设备勾选“使用该设备”和“启用输出”。
- 用“测试此设备配置”从低强度验证设备、通道和波形。
- 确认没有按过 F12；如果顶部显示已急停，请点击“恢复设备联动”。
- 郊狼还会受 A/B BF 软上限限制。

### 状态结束后仍输出

持续事件正常情况下会立即撤销，异常情况下最迟约 1.2 秒停止。必要时先按 `F12`，再查看“全局设置”里的事件诊断和 `BepInEx/LogOutput.log`。

## 安全说明

- 第一次连接或更换电极位置后，从最低强度开始测试。
- 不要把电极放在头部、颈部、胸前或跨越心脏的位置。
- 不要在驾驶、操作机器、靠近水源或无法立即停止设备的情况下使用。
- 身体不适、设备行为异常或连接失控时立即按 `F12`，并关闭设备电源。
- 本项目只提供软件联动能力；请遵守设备厂商说明，并自行评估使用风险。

## 开发和构建

仓库不包含游戏本体和 `mod_out` 发行目录。开发时需要把游戏放入本地 `Game` 目录，并先启动一次 BepInEx 生成 `Game/BepInEx/interop`。

```powershell
.\build.ps1
```

构建脚本会运行协议与事件逻辑测试，编译 `LLJDeviceLink.dll`，然后同步到本地 `Game` 和 `mod_out`。源码结构：

- `src/LLJDeviceLink`：Mod、BLE、协议、事件路由和界面源码
- `tests/ProtocolSelfTest`：协议封包、强度计算、事件目录与迁移测试
- `tools/AssemblyCatalog`：IL2CPP 互操作程序集类型检查工具
- `waveforms`：三类设备的内置波形
- `协议`：设备协议资料与示例

## 第三方组件

发行包包含 BepInEx 6 IL2CPP 运行环境。第三方组件说明见 [THIRD_PARTY.md](THIRD_PARTY.md)。
